> 版本：v1.0
> 日期：2026-05-23

> 受众：产品 / 设计 / 前端 / 后端 / 测试 / 运营

---

## 一、产品定位

**一句话定位**：以 AI 为引擎、以「母婴妈妈全周期（孕期→月子→辅食→儿童餐）」为切入点的私域健康饮食小程序。

**M1 切入点**：月子/哺乳阶段（付费意愿最强、生命周期 3-6 个月）。

**核心价值主张**：每一口都为孩子和妈妈定制。

---

## 二、信息架构（IA）

```
小肚兜 AI（微信小程序）
├── 🏠 首页              阶段卡 / AI 入口 / 今日三餐 / 营养雷达
├── 📖 菜谱              阶段菜谱库 / 收藏 / 搜索

```

## 四、核心 User Journey

### J1 首次进入

```
微信授权 → 阶段画像 4 步 → 首页 → 引导拍照
```

### J2 AI 推荐闭环（核心闭环）

```
首页 → 拍照 → 识别 → 调整 → 推荐 → 详情 → 收藏/加入今日
```

### J3 缺料采购闭环（CPS 变现）

```
详情 → 缺料 → 加购物车 → 跳盒马/美团（带 token CPS）→ 返回打卡
```

### J4 阶段升级闭环（LTV 延长）

```
月子第 38 天 → 系统推送「即将进入辅食期」 → 我的页升级入口 → 续费辅食年卡
```

---

## 五、关键设计原则

1. **阶段驱动**：每个页面都体现"当前阶段"，强化用户身份感
2. **AI 价值显性化**：分数、reason、营养标签必须可见
3. **硬规则零容忍**：过敏/忌口在前端二次确认，后端硬拦截
4. **社交轻量化**：妈妈圈做引流而非沉浸，避免与小红书正面对打
5. **变现路径不强推**：CPS 跳转用「一键购买」自然引导，不打断核心体验

## 六、视觉风格建议

| 维度 | 建议 |
|---|---|
| 主色 | 暖橙色（#FF8866）— 温馨、食欲、母婴感 |
| 辅色 | 奶油白 / 浅薄荷绿（健康感） |
| 字体 | 系统默认（PingFang/Roboto），标题加粗 |
| 圆角 | 12-16px，柔和 |
| 插画 | 手绘风格，避免冷硬 |
| 暗黑模式 | M2 后再做 |

## 七、与竞品的差异化要点

| 维度 | 下厨房 | 薄荷健康 | 小红书 | 小肚兜 AI |
|---|---|---|---|---|
| 核心 | 通用菜谱 | 减脂卡路里 | 内容社区 | 阶段化 + AI |
| 个性化 | 弱 | 中 | 弱 | **强** |
| 母婴专项 | 无 | 无 | 散乱 | **核心** |
| 闭环 | 菜谱 | 工具 | 内容 | **工具+服务+电商** |

**差异化一句话**：别人卖菜谱，我们卖「这一阶段的你和宝宝该吃什么」。
